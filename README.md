# customer_behviour_analysis
Data Analytics Project showcasing customer behavior using Python, SQL and Power BI. 
Customer Shopping Behaviour Analysis
Overview
This project analyzes customer shopping behavior using transactional data (3,900 purchases across multiple categories).
The goal is to uncover insights into spending patterns, customer segments, product preferences, and subscription behaviors — and present them through SQL queries, Python analysis, and interactive dashboards.

Dataset
Rows: 3,900
Columns: 18
Features:
  Demographics: Age, Gender, Location, Subscription Status
  Purchase details: Item, Category, Amount, Season, Size, Color
  Shopping behavior: Discounts, Promo Codes, Frequency, Review Ratings, Shipping Type

Tools & Technologies
Python (Pandas, NumPy, Matplotlib, Seaborn) – Data loading, cleaning, EDA
SQL (PostgreSQL / MySQL / SQL Server) – Business queries & structured analysis
Power BI – Interactive dashboards & visualization
Gamma – Auto‑generated presentation slides (PPT)
Jupyter Notebook – Code execution & documentation

Steps
Data Loading – Import CSV into Python using Pandas.
Data Cleaning – Handle missing values, standardize columns, feature engineering.
Exploratory Data Analysis (EDA) – Summary statistics, distributions, correlations.
SQL Analysis – Run queries for revenue by gender, top products, shipping comparisons, customer segmentation, etc.
Dashboard – Build Power BI visuals for demographics, revenue trends, product performance.
Report – Document findings in a structured project report.
Presentation – Create recruiter‑friendly PPT using Gamma.

Dashboard
The Power BI dashboard includes:
Revenue by Age Group & Gender
Top Products by Rating & Category
Discount vs. Non‑Discount Purchase
Shipping Type Comparison
Subscriber vs. Non‑Subscriber Analysis

Results
Majority of revenue comes from male customers aged 35–50.
Clothing is the most purchased category.
Spring & Winter seasons show peak shopping activity.
Subscribers spend more and purchase more frequently.
Discounts drive sales but require margin control.

How to Run
1. Clone the repository:
  git clone https://github.com/yourusername/customer-shopping-behaviour.git
2. Install dependencies:
  pip install -r requirements.txt
3. Run the Jupyter Notebook for Python EDA.
4. Load cleaned data into MySQL Server.
5. Execute SQL queries from the sql_queries.sql file.
6. Open the Power BI dashboard (dashboard.pbix).
7. Review the project report (report.docx) and Gamma presentation (presentation.pptx).
